# Project City

**Turn any project into a living city map.**

Project City is a local, offline application that helps you organize, visualize, and track projects in a unique way. Instead of traditional lists or diagrams, your project is represented as an interactive city map — where each part of the work becomes a district.

---

## Live Demo

**Project Link:** https://supritha-devi.shinyapps.io/project-city-app/

---

## Features

- **Account System** — Create an account and log in securely (username + password)
- **Interactive City Map** — Visual representation of your project as a city
- **District Management** — Edit titles, descriptions, and progress status
- **Progress Tracking** — Mark each part as `Not Started`, `In Progress`, or `Done`
- **Clickable Districts** — Click any area on the map to edit it instantly
- **Activity History** — Automatic log of your actions
- **Export to HTML** — Download a clean version of your project map
- **Fully Offline** — Works completely without internet after setup
